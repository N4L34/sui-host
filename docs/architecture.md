# Архитектура

Одна машина дома. Ubuntu 26.04.1, x86_64, 16 ядер, 12 ГиБ памяти, диск около 98 ГБ. Имя изделия SuiPlay0X1. Пользователь Linux `sui`. Часы хоста в UTC, контейнеры в `Europe/Moscow`.

Tailscale — единственная дверь для людей. Имя `sui.example.com`, IPv4 `100.64.0.10`. В квартирной сети интерфейс `wlp2s0`, адрес `192.0.2.15`. Публичного DNS и входящего порта из интернета нет.

```text
телефон в Tailscale
        |
        v
Tailscale Serve на sui
        |
        +-- :443 /             Grafana      127.0.0.1:3000
        +-- :443 /_matrix      Synapse      127.0.0.1:8008
        +-- :443 /_synapse     Synapse
        +-- :443 /.well-known  Synapse
        +-- :8443              Element Web  127.0.0.1:8080
        +-- :8444              звонки       127.0.0.1:7882
```

Порт `:3443` выключен. Если `https://sui.example.com/_matrix/client/versions` отдаёт не JSON Matrix, маршрут Serve сломан и его чинят сразу.

Медиа звонков не идёт через Serve. LiveKit слушает TCP `7881` и UDP `50000-50100` только на `100.64.0.10`. Сигналинг LiveKit `7880` остаётся на `127.0.0.1`.

## Слои

1. Хост. Docker, Tailscale, systemd, экран приставки, каталог `/home/sui`.
2. Платформа. Проект Compose `sui` в `/home/sui/sui-host`. Prometheus, Grafana, Loki, Alloy, Alertmanager, cAdvisor, node-exporter, blackbox, экспортёр Postgres. Сеть Docker называется `sui`.
3. Чат «Свои». Проект Compose `svoi` в `/home/sui/tailnet-messenger`. Synapse, Postgres, Element, звонки. К платформе он подключён сетью `sui`, как любой другой сервис. Своя сеть `data` с базой наружу из проекта не отдаётся.
4. Отдельные программы хозяина. Сейчас это бот госномеров `avtobot`: он не в Docker, его поднимает systemd, а локальный прокси слушает только `127.0.0.1:10818`.

Чат, платформа и бот госномеров не делят базу. Общее: машина, Tailscale, сеть `sui` у контейнеров и выход к Telegram через закреплённый адрес `149.154.167.220`, потому что имя `api.telegram.org` с приставки не резолвится.

Postgres сидит в сети `svoi_data` с `internal: true` и на хост не публикуется. Экспортёр метрик базы входит в эту сеть и в `sui`. Саму базу к `sui` не подключают: новый сервис не должен видеть Postgres чата.

Регистрация на Synapse закрыта. Слушателя федерации нет. Имя сервера Matrix навсегда `sui.example.com`.

Grafana открыта с корня `https://sui.example.com/`. Логин `admin`. Пароль лежит в файле на приставке и в этот репозиторий не входит.

История графиков и журналов осталась в томах `svoi_prom-data`, `svoi_grafana-data`, `svoi_loki-data`, `svoi_alert-data`, `svoi_alloy-data`. Их создал прежний проект чата. Платформа берёт их как внешние и не удаляет.

## Что появляется у нового сервиса само

Контейнер на этой машине виден cAdvisor и Alloy через сокет Docker. Память, CPU, перезапуски и журнал попадают в Grafana и Loki без правки конфигов.

Сеть `sui` и метки на контейнере добавляют проверку HTTP, сбор `/metrics` и, если стоит `sui.alert=page`, ночной Telegram. Список целей пишет `scripts/discover.py` раз в 15 секунд. Prometheus его только читает.

Без метки `sui.alert=page` падение проверки график портит и ночью не будит. Диск, бэкап, память машины, подмена адреса чата и готовность звонков размечены отдельно и от нового сервиса не зависят.

`avtobot` в эти графики не попадает: он не контейнер. Новый процесс на хосте лучше сразу собрать контейнером.
