# Архитектура

Одна машина дома. Ubuntu 26.04.1, x86_64, 16 ядер, 12 ГиБ памяти, диск около 98 ГБ. Имя изделия SuiPlay0X1. Пользователь Linux `sui`. Часы хоста в UTC, контейнеры чата в `Europe/Moscow`.

Tailscale — единственная дверь для людей. Имя `sui.example.com`, IPv4 `100.64.0.10`. В квартирной сети интерфейс `wlp2s0`, адрес `192.0.2.15`. Публичного DNS и входящего порта из интернета у чата нет.

```text
телефон в Tailscale
        |
        v
Tailscale Serve на sui
        |
        +-- :443 /             Grafana      127.0.0.1:3000
        +-- :443 /_matrix      Synapse      127.0.0.1:8008
        +-- :443 /_synapse     Synapse
        +-- :443 /.well-known  Synapse
        +-- :8443              Element Web  127.0.0.1:8080
        +-- :8444              звонки       127.0.0.1:7882
```

Порт `:3443` выключен. Если `https://sui.example.com/_matrix/client/versions` отдаёт не JSON Matrix, маршрут Serve сломан и его чинят сразу.

Медиа звонков не идёт через Serve. LiveKit слушает TCP `7881` и UDP `50000-50100` только на `100.64.0.10`. Сигналинг LiveKit `7880` остаётся на `127.0.0.1`.

## Три слоя

1. Хост. Docker, Tailscale, systemd, экран приставки, каталог `/home/sui`.
2. Чат. Один проект Compose `svoi` в `/home/sui/tailnet-messenger`. Три файла: `deploy/compose.yml`, `deploy/compose.calls.yml`, `deploy/compose.observe.yml`.
3. Отдельные программы хозяина. Сейчас это бот госномеров `avtobot`: он не в Docker, его поднимает systemd, а локальный прокси слушает только `127.0.0.1:10818`.

Чат и бот госномеров не делят базу и не ходят друг в друга. Общее у них одно: машина, Tailscale и выход к Telegram через закреплённый адрес `149.154.167.220`, потому что имя `api.telegram.org` с приставки не резолвится.

## Чат внутри Compose

Postgres сидит в сети `data` с `internal: true` и на хост не публикуется. Synapse публикует только `127.0.0.1:8008` и ходит в Postgres по сети `data`. Element Web публикует `127.0.0.1:8080`. Наружу эти порты не торчат.

Регистрация на Synapse закрыта. Слушателя федерации нет, `federation_domain_whitelist` пустой. Имя сервера Matrix навсегда `sui.example.com`. Его уже носят адреса `@user:sui.example.com`.

Мониторинг живёт в том же проекте `svoi`, профиль observe включён. cAdvisor и Alloy смотрят сокет Docker, поэтому видят контейнеры этого проекта. Grafana открыта с корня `https://sui.example.com/`. Логин `admin`. Пароль лежит в файле на приставке и в этот репозиторий не входит.

## Что сознательно не сделано

Второго узла нет. Kubernetes нет. Файрвол хоста с политикой DROP этот проект не ставит. Headscale не поднят. Порт `8448` не опубликован. Медиа не висит на `0.0.0.0`.

Мониторинг пока не вынут в отдельный проект. Пока сервис на машине по сути один, общий стек наблюдения живёт рядом с чатом. Второй самостоятельный продукт можно будет вынести в свой Compose и оставить ему те же графики, когда он появится.
