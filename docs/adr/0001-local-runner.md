# Локальный раннер для выкладки

Приставка не принимает входящий SSH из интернета. Раннер GitHub до `100.64.0.10` сам не доходит. Tailscale Funnel для этого не открывается.

Выкладка выполняется процессом на самой приставке. Он опрашивает GitHub по исходящему HTTPS. Проверки pull request остаются на `ubuntu-latest`: код из pull request на машину с сокетом Docker не попадает.

Раннер — отдельный Compose, сокет Docker только у него, регистрация только на `N4L34/sui-host`. Токен в git не хранится. Папку `chat` этот workflow не поднимает, пока живой каталог чата не перенесён.
