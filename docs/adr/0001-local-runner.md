# Локальный раннер для выкладки

Self-hosted хост не принимает входящие SSH-подключения из интернета. Раннер самостоятельно опрашивает GitHub по исходящему HTTPS.

Проверки pull request выполняются на `ubuntu-latest`; код из pull request не запускается на машине с доступом к Docker. Выкладка разрешается только после успешной CI-проверки коммита в основной ветке этого же репозитория.

Раннер работает отдельным Compose-сервисом. Его регистрационный токен задаётся локально и не хранится в git. Процедура выкладки синхронизирует управляемые файлы и перезапускает только изменённые проекты.
