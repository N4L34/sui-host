# Бэкап и восстановление

RPO — 1 час. RTO — 60 минут на базу этого размера. Таймер `svoi-backup.timer` на Ubuntu запускает `make backup` каждый час, с `Persistent=true` и случайной задержкой до 5 минут. На Mac таймера нет: бэкап запускают сами.

## Что входит в снимок

Каталог `backups/<время UTC>/`:

1. `synapse-data.tar` — том `svoi_synapse-data`. Сначала он. Там ключ подписи `/data/signing.key` и медиа.
2. `postgres.dump` — `pg_dump -Fc` базы `synapse`. Том Postgres целиком при работающем сервере не архивируют.
3. `secrets.tar` — `secrets/`, `.env`, отрендеренные `homeserver.yaml` и `element-config.json`. Macaroon лежит в yaml, не только в `secrets/`.
4. `meta.txt` — время, имя сервера, теги образов.

Права на три архива — `600`. На диске остаются 14 последних каталогов. Забирайте `backups/` вместе с остальными копиями этого сервера.

Если в `.env` задан `RESTIC_REPOSITORY`, тот же снимок дополнительно уходит в restic. Пустое значение означает: только каталог `backups/`. Пароль restic создаёт `make init`. Первый раз для нового репозитория: `make restic-init`.

## Учебное восстановление

`make drill` берёт самый новый `backups/*/postgres.dump`, поднимает временный контейнер `svoi-drill-<pid>` и считает строки в `users`. Боевые тома не трогает. Ключ подписи drill не проверяет. Контейнер удаляется в `trap`.

Ноль пользователей на пустой учебной базе — нормальный результат до первой учётки. Ошибка `pg_restore` — не норма.

## Боевое восстановление

```bash
make restore CONFIRM=yes SNAPSHOT=backups/20261019T120000Z
```

Без `CONFIRM=yes` скрипт выходит сразу. Он останавливает все три compose-файла, возвращает секреты, очищает том Synapse и разворачивает tar, заново создаёт базу и делает `pg_restore`. Друзьям после этого пишут другим каналом: сообщения за время простоя нужно отправить ещё раз.

Нельзя восстанавливать только дамп в новый пустой том Synapse. Ключ подписи должен быть из того же снимка, что и база. Порядок в снимке как раз такой: сначала медиа и ключ, потом дамп.

Пошагово, включая отказ: `docs/runbooks/restore.md`.
