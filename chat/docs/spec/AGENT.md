# Заметки для разработки

Общие правила репозитория лежат в корневом `AGENTS.md`. Требования к Matrix-сервису описаны в `SPEC.md`, решения — в `docs/adr/`.

## Изменения

- Долгие процессы запускайте в Compose; секреты храните в локальных файлах из `secrets/` и `.env`, не в git.
- Публикуйте host-порты только на loopback. Не используйте `privileged` и `network_mode: host` для прикладных сервисов.
- Фиксируйте версии образов и задавайте ограничения ресурсов, ротацию журналов и healthcheck.
- Перед изменением конфигурации проверьте `docker compose config` и запустите `make ci`.
- Не записывайте в документацию реальные адреса, имена пользователей, токены или состояние конкретного хоста.

## Структура

Compose-файлы чата находятся в `deploy/`. Вызовы включаются отдельно через `ENABLE_CALLS`. Пример окружения — `.env.example`; персональные параметры перед запуском задаются локально.

Для новых общих сервисов узла используйте инструкции из корневого `docs/new-service.md`.
