# ADR 0001. Homeserver — Synapse

## Статус

Принято. Образ `ghcr.io/element-hq/synapse:v1.163.0`, база Postgres 17.

## Контекст

Нужен один homeserver для своих. Кандидаты, которые рассматривались: Synapse, Conduit и Tuwunel. Группа сидит на iPhone в Element X, иногда на Mac, редко на Android. Сервер должен уметь пуши Element, шифрование по умолчанию, закрытую регистрацию и предсказуемый бэкап Postgres.

## Решение

Ставим Synapse и Postgres. Конфиг генерирует `scripts/render_config.py`. SQLite не используем.

## Почему не Tuwunel и не Conduit

Tuwunel на момент выбора (ветка около v1.9) не давал спокойной миграции обратно и имел сбои sliding sync, на котором сидит Element X. Откат с него — это новый сервер, а не смена образа. Conduit для этой группы не выигрывает столько, сколько стоит второй путь сопровождения.

Synapse тяжелее по памяти. На 2 vCPU и 4 ГБ это приемлемо: лимит контейнера 1536 МБ, кэш `global_factor: 0.5`, presence выключен.

## Последствия

Обновление — смена тега после бэкапа и `make smoke`. Ключ подписи живёт в томе `svoi_synapse-data`. Потеря тома при живой базе ломает подписи сервера, даже когда федерация выключена.
