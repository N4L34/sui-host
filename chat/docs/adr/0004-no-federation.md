# ADR 0004. Федерация выключена, регистрация закрыта

## Статус

Принято.

## Контекст

Чат для своих. Чужие homeserver не должны читать каталог, стучаться на 8448 и заводить у нас учётки. Открытая регистрация на сервере без публичного входа всё равно опасна: любой, кто оказался в tailnet, смог бы создать аккаунт.

## Решение

Рендер фиксирует:

- слушатель клиента без ресурса `federation`;
- `federation_domain_whitelist: []` — пустой список в Synapse выключает федерацию;
- `trusted_key_servers: []` и `suppress_key_server_warning: true`;
- `serve_server_wellknown` не включаем;
- `enable_registration: false`, гости выключены;
- превью ссылок выключены;
- `encryption_enabled_by_default: true`;
- профили только для вошедших, публичный каталог комнат без входа и через федерацию выключен.

Аккаунты создаёт `register_new_matrix_user` с `registration_shared_secret`. Флаг администратора ставится только у `make admin`. Секрет не открывает `POST /register`.

`make smoke` падает, если регистрация ответила 200 или если в `compose ps` виден порт 8448.

## Последствия

Написать человеку на matrix.org с этого сервера нельзя. Это и есть цель. Комнаты по умолчанию шифруются, но сервер всё равно видит метаданные: кто в комнате, когда писали, имена комнат. Смотрите модель угроз.

Сброс пароля — «спросить хозяина». Самообслуживания нет.
