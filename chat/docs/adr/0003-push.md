# ADR 0003. Пуши через шлюз Element, без Sygnal

## Статус

Принято.

## Контекст

iPhone не держит исходящее соединение к homeserver, когда приложение спит. Баннер приходит только через APNs. Свой Sygnal требует ключ Apple, а этот ключ принадлежит приложению Element из App Store, не нам. Свой клиент мы не собираем.

Домашний сервер при этом не торчит в интернет. Шлюз не может сам сходить за текстом сообщения.

## Решение

Оставляем стандартный шлюз Element, который прописан в Element X:

`https://matrix.org/_matrix/push/v1/notify`

Synapse отдаёт туда идентификатор события, не тело. Приложение просыпается и само читает событие с `https://<наш-сервер>`. Поэтому Tailscale на телефоне должен быть включён всегда: VPN On Demand = Always для Wi-Fi и для сотовой сети.

На Android тот же принцип через FCM.

## Последствия

Если туннель на телефоне лежит, баннер может быть пустым или общим. Это честное ограничение, не авария сервера. Время доставки пуша в SLO не входит: его держат Apple, Google и VPN.

Хосту нужен исходящий HTTPS до matrix.org. Входящий порт для пушей не нужен.

Проверка: телефон на сотовой сети, Wi-Fi выключен, Tailscale подключён, сообщение с другого устройства, баннер пришёл. Если баннера нет, смотрите `docs/runbooks/push-not-arriving.md`.
