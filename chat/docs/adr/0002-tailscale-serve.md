# ADR 0002. Дверь в чат — Tailscale Serve

## Статус

Принято.

## Контекст

Чат не должен висеть в публичном DNS и не должен принимать соединения из интернета. Людям всё равно нужен HTTPS, которому доверяет Element X на iPhone. Свой домен и публичный Let's Encrypt требуют входящего порта или DNS-01 и отдельной возни с сертификатами на телефонах.

## Решение

Имя сервера — MagicDNS-имя узла, `*.ts.net`. `tailscale serve` выпускает сертификат Tailscale и проксирует HTTPS на loopback:

- 443 → `127.0.0.1:8008` Synapse
- 8443 → `127.0.0.1:8080` Element Web
- 8444 → звонки, только когда профиль включён
- 3443 → Grafana, только когда она уже отвечает на loopback

Публичный Caddy с ACME на 443 не ставим. Порт 8448 не публикуем.

Файрвол VPS этот проект не настраивает. На той же машине могут жить другие сервисы. Чат их не закрывает: его порты остаются на localhost, а медиа звонков, если их включат, вешаются только на адрес Tailscale.

## Почему не Headscale в том же compose

Headscale нужен, когда пользователей больше лимита Personal или не хочется координации Tailscale. Вместе с ним пропадают автоматические сертификаты `tailscale serve` и простой вход на iPhone. Это отдельный проект, не второй файл compose рядом с Synapse. Смотрите `docs/guides/headscale.md`.

## Последствия

Без Tailscale на клиенте чат не открывается, в том числе из дома: MagicDNS резолвится только в tailnet. Домашний SSID из VPN On Demand не исключают. Хост, который спит, гасит чат для всех.
