# «Свои» на Mac

Аккаунт создаёт оператор. Имя и одноразовый пароль он говорит лично или в канале, который не является этим чатом. Адрес в примерах — `https://messenger.example.com`. Подставьте адрес, который прислал оператор.

1. Установите Tailscale и войдите в тот же tailnet.
2. Оставьте Tailscale подключённым. Не исключайте домашнюю сеть Wi-Fi. Имя сервера находится только через Tailscale, в том числе дома.
3. Для обычной работы установите Element Desktop с сайта element.io. При первом запуске укажите homeserver `https://messenger.example.com`.
4. Если ставить приложение не хотите, откройте в браузере `https://messenger.example.com:8443`. Это Element Web. Homeserver там уже заполнен. Element Desktop — приложение на каждый день. Element Web — вариант без установки.
5. Войдите именем и одноразовым паролем от оператора. Сразу смените пароль.
6. Если это новая сессия, подтвердите её сравнением эмодзи с оператором или со своей уже проверенной сессией. Ключ восстановления настраивают в Element так же, как на iPhone: хранилище ключей в разделе шифрования. Ключ храните не только на этом Mac.
