# «Свои» на Android

Этим путём пользуются редко. Аккаунт создаёт оператор. Самостоятельно не регистрируйтесь. Имя и одноразовый пароль оператор передаёт лично или в другом канале.

1. Установите Tailscale из Play Store и войдите в tailnet, куда вас пригласили.
2. Включите для Tailscale always-on VPN. Домашнюю сеть Wi-Fi не исключайте. Имя сервера находится только через Tailscale, даже дома.
3. Установите Element X из Play Store.
4. На экране выбора сервера введите тот же адрес, например `https://messenger.example.com`.
5. Войдите учётной записью оператора, смените пароль, включите хранилище ключей в Settings → Encryption → Recovery и проверьте оператора сравнением эмодзи.

Пробуждение приложения приносит FCM. В этом сигнале нет текста. Текст Element X забирает с сервера, поэтому Tailscale должен быть подключён.
