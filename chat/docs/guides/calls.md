# Звонки

Звонки выключены. Голосовые сообщения при этом работают: это обычные файлы в чате, LiveKit для них не нужен. Текст должен работать и со звонками, и без них.

Включайте звонки только когда текстовый чат уже проходит `make smoke`.

1. В `.env` поставьте `ENABLE_CALLS=true`.
2. Сверьте адрес, который LiveKit будет объявлять:

```bash
tailscale ip -4
```

В `secrets/tailscale_ipv4` должна лежать та же строка. `make init` записывает её, если Tailscale уже был установлен. Если файл пуст или адрес другой, запишите туда вывод `tailscale ip -4`.

3. Пересоберите конфиг, поднимите стек и опубликуйте HTTPS:

```bash
make render
make up
make serve
```

`make render` пишет в конфиг LiveKit этот Tailscale IPv4 и не подставляет публичный адрес машины. Порты медиа вешаются на этот же адрес, не на все интерфейсы VPS. `make serve` добавляет `https://messenger.example.com:8444`. В ACL для `tag:messenger` участникам нужны `tcp/8444`, `tcp/7881`, `udp/7881` и `udp/50000-50100`. Файрвол хоста из-за звонков не меняют.

`make up` при включённых звонках ещё поднимает внутренний прокси `call-dial`. Сервис токенов проверяет личность звонящего по `https://<имя-сервера>:8448` и ходит в LiveKit по `https://<имя-сервера>:8444`. Из Docker эти адреса не открываются: Tailscale принимает такие пакеты только со своего интерфейса. Прокси отвечает внутри сети compose сертификатом этой ноды. Порт 8448 на хост не публикуется, слушатель федерации не включается.

4. Проверьте звонок на двух телефонах. На обоих выключите Wi-Fi и оставьте сотовую сеть. Tailscale на обоих должен быть подключён. Сначала отправьте текстовое сообщение. Потом позвоните. После звонка снова отправьте текст.

Если звука или видео нет, обычная причина одна из двух. Кандидаты ICE указывают на публичный IP, либо UDP в tailnet закрыт. Откройте `deploy/rendered/livekit.yaml` и проверьте `node_ip`: там должен быть адрес из `tailscale ip -4`, а `use_external_ip` должен быть `false`. Там же должен быть `use_ice_lite: true`. Полный ICE-агент сам проверяет домашний Wi-Fi и публичный адрес телефона, эти пары выигрывают у адреса Tailscale и обрываются примерно через 15 секунд. Lite отвечает только на проверки, которые доходят до адреса Tailscale. Если в файле другой адрес, исправьте `secrets/tailscale_ipv4` и снова выполните `make render`, `make up` и `make serve`.

DERP переносит трафик Tailscale, когда прямой UDP tailnet недоступен. Медиа LiveKit он не заменяет. Закрытый UDP даёт звонок без звука. Текстовый чат при этом обязан продолжать работать.

Если Synapse не принимает блок `matrix_rtc` и контейнер уходит в перезапуск, поставьте `ENABLE_CALLS=false` и повторите `make render`, `make up` и `make serve`. Текст от звонков не зависит.

Чтобы снова выключить звонки, поставьте `ENABLE_CALLS=false` и повторите те же три команды.
