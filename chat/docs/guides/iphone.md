# «Свои» на iPhone

Аккаунт создаёт оператор. Сами регистрацию не проходите. Имя и одноразовый пароль оператор говорит лично или в другом канале, не в этом чате. Имя выглядит как `@alice:messenger.example.com`. Адрес сервера оператор присылает отдельно. В примерах это `https://messenger.example.com`.

1. Установите Tailscale из App Store.
2. Войдите в tailnet, в который вас пригласил оператор.
3. Откройте VPN On Demand. Поставьте Always для Wi-Fi и Always для Cellular.
4. Не исключайте домашнюю сеть Wi-Fi. Имя сервера находится только через Tailscale, в том числе когда вы дома.
5. Установите Element X из App Store.
6. На экране выбора сервера введите адрес, который прислал оператор, например `https://messenger.example.com`. Не выбирайте `matrix.org` и не создавайте новый аккаунт.
7. Введите имя и одноразовый пароль, которые дал оператор.
8. Сразу после входа смените пароль в настройках Element X.
9. Настройте восстановление. Откройте Element X → Settings → Encryption → Recovery и включите хранилище ключей. Сохраните ключ восстановления не в этом телефоне. Без него старую зашифрованную переписку нельзя прочитать.
10. Проверьте оператора сравнением эмодзи. Нажимайте, что набор совпал, только если на обоих экранах одни и те же эмодзи.

Уведомление с текстом приходит только пока Tailscale подключён. Apple будит Element X через шлюз Element на matrix.org. В сигнале пробуждения нет текста сообщения. После пробуждения Element X сам забирает текст с нашего сервера, а сервер доступен только через Tailscale. Если Tailscale выключен, сигнал может дойти, но текста в уведомлении не будет. Поэтому VPN On Demand оставляют Always и для Wi-Fi, и для сотовой сети, включая дом.
