# sui

Домашняя приставка SuiPlay0X1. Это один узел в Tailscale, не публичный сервер. Снаружи у чата нет порта. Друзья попадают сюда только из tailnet.

Снимок на 28 октября 2026. Код сервисов здесь не лежит. Здесь схема машины и правила, по которым на неё добавляют следующее.

| Репозиторий | Что это |
| --- | --- |
| `N4L34/sui-host` | эта машина: архитектура, сервисы, как работать |
| `N4L34/tailnet-messenger` | чат «Свои»: Synapse, Element, звонки, мониторинг |
| `N4L34/svoi` | заметки хозяина о чате |
